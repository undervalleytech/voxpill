================================================================================
VOXPILL — Publier une mise à jour (release GitHub + installeur GPU sur ton PC)
================================================================================

AVANT DE COMMENCER
------------------
• Sur ton PC : lancer le runner GitHub (dossier actions-runner) : run.cmd
  La fenêtre doit rester ouverte tant que le build tourne sur GitHub Actions.

• Sur GitHub : secrets TAURI_SIGNING_PRIVATE_KEY déjà configuré (clé privée .key).


À CHAQUE NOUVELLE VERSION
-------------------------

1) Monter le numéro de version AU MÊME ENDROIT partout, par exemple 0.1.4 :
   - package.json          → "version": "0.1.4"
   - src-tauri/tauri.conf.json → "version": "0.1.4"
   - src-tauri/Cargo.toml  → version = "0.1.4"

2) Mettre à jour Cargo.lock (dans un terminal, dossier src-tauri) :
   cargo update -p voxpill

3) Enregistrer le code et envoyer sur GitHub :
   git add -A
   git commit -m "chore: bump 0.1.4"
   git push origin main

4) Créer un tag qui commence par v + le même numéro, puis l’envoyer :
   git tag -a v0.1.4 -m "Voxpill v0.1.4"
   git push origin v0.1.4

5) Aller sur GitHub → onglet Actions → attendre que le workflow "Release" soit VERT.

6) Aller sur GitHub → Releases → télécharger l’installeur si besoin.
   Les utilisateurs avec une ancienne version peuvent utiliser "Check for updates".


RAPPEL
------
• Sans run.cmd ouvert sur ton PC, le job reste en attente ou échoue.
• Ne réutilise pas un tag déjà poussé : à chaque release, un nouveau numéro (0.1.5, 0.1.6…).
